Subscription Expiry Checker

This is a C++ program that checks how many days remain before a subscription expires and displays an appropriate message.

Features

- Generates a random number between 0 and 11 to represent the days remaining.
- Displays a message when a subscription has expired or is about to expire.
- Offers renewal discounts of 20% or 10% in eligible cases.
- Uses "if", "else if", and "else" statements.

Requirements

- A C++ compiler, such as GCC ("g++").

How to Compile

g++ main.cpp -o main

How to Run

./main

Concepts Practiced

- Random number generation
- Variables and integers
- Conditional statements
- Output using "cout"
